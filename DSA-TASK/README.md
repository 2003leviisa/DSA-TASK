# Lab 07: Linked Lists, Stacks and Queues

## Introduction

This project contains Java implementations of different data structures, including doubly linked lists, stacks and queues.

The aim is to understand how these data structures work and how they can be implemented using arrays and linked lists.

## Objectives

- Implement a generic doubly linked list.
- Implement a circular doubly linked list.
- Implement stacks using arrays and linked lists.
- Implement queues using arrays and linked lists.
- Understand the operations performed on each data structure.

## Project Contents

### Linked Lists
- `DLinkedList.java` - Doubly linked list using a dummy head node.
- `DDLinkedList.java` - Doubly linked list using a true head node.
- `CDLinkedList.java` - Circular doubly linked list.

### Stacks
- `ArrayStack.java` - Array-based stack with dynamic resizing.
- `LinkedStack.java` - Linked-list-based stack with top at the head.
- `NLinkedStack.java` - Linked-list-based stack with top at the tail.

### Queues
- `LinkedQueue.java` - Linked queue with front at the head.
- `LinkedQueue2.java` - Linked queue with front at the tail.
- `ArrayQueue.java` - Circular array-based queue with dynamic resizing.

### Interfaces
- `List.java`
- `Stack.java`
- `Queue.java`

### Testing
- `Main.java` - Contains basic tests for the implemented data structures.

## Technologies Used

- Java
- Object-Oriented Programming
- Generic Classes
- Data Structures and Algorithms

## How to Run

1. Clone or download the repository.
2. Open the project folder in a Java IDE.
3. Make sure all Java files are in the same default package.
4. Run `Main.java` to test the implementations.

## Conclusion

The project demonstrates how linked lists, stacks and queues can be implemented in Java. It also shows the differences between array-based and linked-list-based implementations and their operations.
